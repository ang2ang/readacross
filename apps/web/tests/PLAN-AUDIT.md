# 轻量对照阅读计划复核

对照已批准的实现计划及本地 PLAN.md 复核。保持现有 Web 流程，没有新增书库、全文自动翻译、生产依赖、共享 core API 或部署配置。

## 本轮修复

- 容量区收敛为一行用量和清理入口，移除常驻策略说明。
- 清空与单项删除共用应用内英文确认框，消除浏览器系统按钮与正文的语言混用；默认聚焦 Cancel，支持 Tab 循环、Esc、取消及焦点返回。
- 删除失败保留当前完整译文；删除完成后的回调只更新对应会话。删除标记防止旧标签页的译文、原文件或位置回调重建已删除记录。
- 恢复读取等待此前排队的写入，避免刚完成的译文被遗漏。原文件副本写入不阻塞已恢复的阅读页，也不覆盖随后改变的位置与字号。
- 完整译文保存失败后继续标为未保存，后续其他结果保存成功不会掩盖它；再次命中该结果时可重试保存，不调用模型。
- 译文提交同时保存最新位置、字号和译文滚动位置；存储预算计入必要的清理元数据。
- 窄屏定位时收起抽屉，直接展示原文；抽屉处理键盘焦点，与设置及追加内容弹窗协调。
- EPUB 可见内容提取的降级路径按实际阅读容器裁剪；定位前验证原文摘录，失配时降级到章节。PDF 失配时降级到页面，两者显示简短提示，不显示错误高亮。
- 设置草稿按打开周期初始化，编辑事件直接更新草稿，取消不会提交；修复该编辑器和代理类型的既有 lint 问题。

## PDF 缩放回归修复

- 原因：将手动比例乘在变化中的原文栏宽度上，改变了旧版的缩放基准；适合宽度时还重复扣除了内边距。
- 手动缩放恢复为旧版 800px 基准，130% 固定为 1040px，侧栏开关、调宽和窗口变化不改变该比例。适合宽度独立保存，顶部显示实际比例；PDF 按钮标为 Zoom in/out，文本字号沿用原行为。
- 缩放及调宽按视口中心保存原文锚点，等待对应页和尺寸渲染完成后恢复；整页可见时保留原阅读锚点，窄屏往返不会移到空白处。旧的页内位置与字号记录仍能恢复。
- 浏览器在 1280 / 1024 / 390px 验证了手动缩放、平移、适合宽度、侧栏开关及键盘调宽。130% 页宽始终为 1040px，页面横向溢出为 0；缩放前后中心纵向位置偏差小于页面高度的 0.03%。窄屏往返及定位后返回恢复到同一位置，刷新恢复手动比例和页内位置。
- 原生 IndexedDB 检查使用独立测试来源 `zoom-check.localhost:5187`，包含缩放模式与中心锚点的保存。模拟请求计数保持 12，没有新模型请求。

## PDF 原有目录链接修复

- 原因：当前 React-PDF 的 Document 保留首次 onItemClick 回调，回调捕获的 PDF 尚未加载，导致点击目录时直接退出翻页函数。
- 改为通过 ref 调用当前提交的翻页处理器，卸载时清空；沿用现有页码、阅读位置和请求隔离逻辑。
- 在原附件中又发现 `page58` 等名称没有定义目标，文件却含有可校验的页标签。新增内部解析器：正式目标优先，缺失的 `page<label>` 只按唯一的内嵌页标签定位；无法验证时提示，保持当前页。异步解析受会话及导航版本保护。
- 原书目录的 “Process vs. Content 58” 实测跳到 PDF 第 80 页，正文印刷页码为 58。随后恢复第 10 页、120%、纵向 249px 和横向 33px 的原阅读状态。
- 新增 `tests/fixtures/linked.pdf` 和 `tests/pdf-links.html`，在真实阅读器中验证直接目标、命名目标、返回目录、页标签兼容、未解析目标反馈及外部 URL，共 8 项通过；侧栏打开、130% 下使用回车跳至第 3 页，比例保持不变。
- 28 项 Node 检查、Web build、lint 通过。链接操作不调用模型，模拟请求计数保持 12。现有构建体积和 Browserslist 提示仍保留。

## 实际导出内容复核

- 前轮导出测试只检查传入共享 Obsidian 构造器的字段，并未验证最终 Markdown；浏览器验证也不足以发现成品的问题。实际下载后确认：首条译文被输出两次，原文快照、完整提示词、内部 ID、Backlinks 等模板内容混入阅读文档。
- Web 改用内部 Markdown 构造器，不修改共享 core 的导出 API 或扩展。正文按来源顺序输出当前文档的完整译文，每条仅一次，保留标题、列表、表格、代码缩进及硬换行。原文和生成设置快照仍留在本地记录中；导出只在末尾保留来源范围、时间、语言、风格、模型和温度，多种配置及提示词版本如实区分，不输出完整提示词。
- 文档说明仅包含已完成译文；空结果和其他文档记录排除。PDF 保留页码与范围类型，EPUB 的完整 CFI 范围放在末尾。文件名为 `<原文件名去扩展>.translated.md`。
- 实际通过 Export 下载并逐段读取 PDF 与 EPUB 的 Markdown，各 2 条可见完整译文在对应文件中出现次数均为 1，EPUB 不混入 PDF 页码；PDF 的 Copy Markdown 与下载文件逐字一致。操作后恢复原剪贴板，未调用模型，模拟计数仍为 12。
- 原先的字段模拟测试替换为真实 Markdown 断言，覆盖完整长译文、去重、顺序、来源隔离、生成时配置、提示词版本、Markdown 格式和 EPUB CFI。32 项 Node 测试通过；Web build、lint 和 diff 格式检查通过。

边界：导出包含已经完成的各个翻译范围；重叠选区或使用不同设置生成的记录保留，不自动合并成整本译稿，也不包含尚未翻译的页面。

## EPUB 目录与恢复位置修复

- 复现了原问题：点击章节后收起目录会改变原文栏宽度，EPUB.js 的重排随后恢复旧 CFI，把新章节覆盖回旧位置。调整宽度时现在优先使用尚未完成的跳转目标，并等待目录收起后的布局提交。
- 130% 下进一步复现深层锚点落在前一屏。EPUB.js 首次分页早于字号主题应用；按锚点的首个有效文本生成 CFI，主题重排后再次定位。同样处理首次恢复的已保存 CFI，防止非默认字号下的继续阅读偏移。
- 导航带版本检查，新的目录/翻页操作取消旧的异步定位；缺失章节给出简短反馈。目录递归展示全部层级，支持键盘触发。
- 新增 `navigation.epub` 和 `epub-navigation.html`，使用真实阅读器核对目标元素是否稳定处于视口。22 项检查通过：100% / 130% / 70%、翻译栏开关、编码路径、多层与深层锚点、前后翻页、目录开关、来源定位往返、连续点击、无效目标反馈及 130% 深层位置重开恢复。
- 原书《The Soul of an Entrepreneur》实测：100% 从 Copyright 跳至 Chapter 1；130% 跨章至 Chapter 2；刷新/Continue 保留 130% 和章节，再跳至 Chapter 1 成功。全过程不调用模型，模拟请求计数保持 12。
- 32 项 Node 检查、Web build、lint 和 diff 格式检查通过。保留现有 bundle 大小及 Browserslist 提示。
